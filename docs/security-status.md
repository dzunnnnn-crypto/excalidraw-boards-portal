# Состояние зависимостей перед публикацией

## Исправление 24.10.2026, патч 006

Прямая и вложенные зависимости MCP SDK сведены к закреплённой Zod 4.6.7.
Неиспользуемый zod-to-json-schema удалён. Фильтр query_elements переведён
на двухаргументный z.record, поддерживаемый Zod 4. Все массивы в схемах
HTTP/MCP имеют верхнюю границу 10000 значений, проверяемую до обхода детей.
Это ограничение отдельной проверяемой коллекции, не размера всей доски.

Регрессии проверяют отсутствие обхода слишком большой коллекции, один
краткий ответ об ошибке, HTTP 400, отказ MCP без изменения сцены и
сохранность обычных запросов/фильтров. Функциональные и upstream проверки
в Linux прошли; полный npm audit в исправленном дереве: 0 уязвимостей.
Исторический результат до исправления сохранён ниже. Нулевой аудит не
является независимым исследованием безопасности. VPS не обновлялся.

## Исправленная клиентская цепочка

Excalidraw оставлен на 0.18.1. Прямой и вложенный конвертер сведены к
@excalidraw/mermaid-to-excalidraw 2.3.0, Mermaid 11.17.0. Удалена старая
цепочка Mermaid 10.9.4 с DOMPurify 3.1.6. Закреплены DOMPurify 3.4.17,
KaTeX 0.18.2, nanoid 3.3.18 для редактора и 5.1.16 для конвертера,
lodash-es 4.18.1, shell-quote 1.12.0, source-map-js 1.2.2, Vite 6.4.5.
Manifest и lockfile входят в патч с SHA256 в upstream.lock.json.

Конфигурация внешнего Mermaid-конвертера ограничена поддерживаемыми
настройками: форма линий, размер шрифта и лимиты не выше 500 рёбер /
50000 символов. Произвольные securityLevel/themeCSS и неизвестные поля
отклоняются до рендеринга; strict и защищённые параметры задаёт приложение.
Защита относится к внешнему конвертеру приложения. Встроенные возможности
самого Excalidraw используют обновлённые библиотеки, полный отдельный
аудит всех его диалогов не заявляется.

Проверены реальная браузерная конвертация через MCP, flowchart/sequence,
классы и pie (возможен SVG fallback), сохранение и PNG. Формула в подписи
flowchart остаётся обычным текстом: точная математическая вёрстка в
редактируемых блоках не реализована. KaTeX API отдельно проверен с trust:false.

Новая команда npm run check:dependencies проверяет всё дерево до удаления
devDependencies. Сборщик Linux-релиза вызывает её до сборки и prune;
при уязвимостях или недоступном/невалидном ответе аудит блокирует релиз.
Состояние advisory может измениться после даты проверки.

Основания: [Mermaid](https://github.com/mermaid-js/mermaid/security/advisories/GHSA-6x64-9x62-f2gx),
[DOMPurify 3.4.17](https://github.com/cure53/DOMPurify/releases/tag/3.4.17).

## История до патча 005

До исправления полный npm audit: 16 затронутых пакетов (2 critical, 4 high, 9 moderate,
1 low), включая транзитивные зависимости. Это не число независимых атак.
В дереве присутствуют DOMPurify, Mermaid, nanoid, lodash-es, Excalidraw,
shell-quote, source-map-js, Vite и связанные пакеты.

devDependency означает способ установки, а не отсутствие кода в браузерной
сборке. Удаление dev node_modules из архива не устраняет автоматически
риски встроенного frontend. Нужно отдельно проверить пути ввода диаграмм,
SVG и формул, реальные диапазоны версий и доступные исправления.

Для части дерева npm не предлагает готового исправления; автоматический
fix --force также предлагает несовместимые изменения Excalidraw. Они не
включались без проверки сохранения функций продукта. Этот пункт закрыт
локальными исправлениями и приёмкой патча 005. Публикация и перенос на VPS
остаются отдельными действиями.

Тестовый экземпляр по умолчанию слушает только 127.0.0.1. Настоящие доски
и ключи не должны попадать в публичный репозиторий.
