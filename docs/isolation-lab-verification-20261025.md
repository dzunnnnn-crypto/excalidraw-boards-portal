# Исторический этап: прототип изоляции, 25.10.2026

На синтетическом Linux-стенде проверялись файловая, процессная и сетевая
границы bubblewrap. Прототип использовал временный preload-адаптер.
На этом этапе аварийное восстановление и штатный запуск ещё не были завершены;
он не является актуальной инструкцией установки.

В следующем этапе preload заменён патчем 007 с нативным Unix-сокетом,
kernel lease и generation readiness. Текущая реализация находится в
`portal/isolated/`, включается конфигурацией основного портала.
