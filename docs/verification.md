# Проверки подготовки

Работа выполняется локально по согласованному плану. GitHub не создан,
действующий VPS не обновлялся. Этот файл будет завершён после Linux-приёмки
и независимого review; незавершённые проверки не считаются пройденными.

Проверено на Windows, Node 24.14.0:

- setup: закреплённый commit, контрольные суммы патчей, повторный запуск и
  отказ затирать неизвестные изменения.
- Конфигурация: локальный HTTP только явно и на loopback, HTTPS cookies для
  сервера, инициализация version:2 без повторного сброса, один владелец auth.
- HTTP/MCP/WebSocket: изоляция, view/edit, гостевой просмотр, отзыв прав и
  ключей, запрет filePath, восстановление после перезапуска.
- Изображение, экспорт PNG, снимки, offline backup и восстановление в другой
  каталог без изменения исходного.
- Браузерный вход, настоящий редактор, гостевой просмотр, мобильная ширина 390.

В исходной проверке durable-state выявлена проблема остановки Windows:
SIGTERM принудительно завершает дочерний процесс. Добавлен закрытый IPC
shutdown, проверка освобождения lock не убиралась. Полный standalone-тест
durable-state на Windows пока завершился native-кодом ошибки; его нельзя
помечать успешным по результатам отдельных тестов. Полная Linux-проверка
и релизы проверяются отдельно.

Технические логи подготовки находятся в исключённом из Git каталоге
.superpowers/sdd/2026-10-23-excalidraw-boards-portal/.
