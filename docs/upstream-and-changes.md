# Основа и мои доработки

Основа: https://github.com/yctimlin/mcp_excalidraw,
коммит 8084a1c8b410d625fcfd59d5cffb32f3a86a2a6f.
Сам редактор, операции с элементами, экспорт, рендеринг и базовая
синхронизация разработаны авторами исходных проектов.

Собственный слой: портал пользователей, личные и общие доски, права
просмотра/редактирования, гостевые ссылки, личные MCP-ключи, выбор доски
в каждом инструменте, ограничение файловых операций и управление процессами.

Патчи:

1. Интеграция портала: относительные пути, сведения о доске, режим просмотра,
   разделы и русский интерфейс.
2. Управление мышью: масштаб у курсора и перемещение правой кнопкой без
   изменения истории сцены.
3. Корректная остановка дочернего редактора через закрытый IPC-канал,
   включая Windows. Проверка освобождения lock сохранена.
4. Исправленные runtime-зависимости с закреплёнными версиями и lockfile.
   Состояние frontend-зависимостей отдельно описано в security-status.md.
5. Обновлённые зависимости браузера и сборки, единый конвертер Mermaid,
   ограничение недоверенной конфигурации. Версия самого Excalidraw сохранена.
6. Zod 4.6.7 для сервера и MCP SDK, удаление неиспользуемого старого
   zod-to-json-schema, адаптация фильтра запросов. Коллекции в схемах
   HTTP/MCP ограничены 10000 элементами до обхода дочерних значений.

7. Штатный Unix-сокет редактора, generation readiness и безопасное
   освобождение владельца после аварии при подтверждённом kernel lease.
   Legacy TCP-режим сохранён.

Изоляция и общий пул реализованы в `portal/isolated/`, включаются явно.
Дополнительно `create_board` умеет атомарно выдать доступ выбранным участникам
и безопасно повторить создание после потери ответа. Это слой портала,
а не функция исходного редактора.

Файлы `deploy/security/` дают отдельный пример ограничения доступа
сервисного UID к локальному API Caddy. Они не устанавливаются автоматически
и требуют проверки UID, unit-файлов и firewall конкретного сервера.

Сборщик дополнений проверяет полный npm audit перед созданием релиза.
Собственный браузерный сценарий tests/browser-security.mjs проверяет новый
конвертер через настоящий MCP и сохраняет скриншоты в приватной .local.

Версия и SHA256 каждого патча перечислены в upstream.lock.json. Новые версии
исходного проекта не устанавливаются автоматически. Для обновления upstream
потребуется проверить патчи и повторить проверки совместимости.
